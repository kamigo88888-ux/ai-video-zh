# AI 電商影片自動中文化系統

上傳英文商品短影音 → 自動辨識後製英文字幕 → Claude AI 幽默改寫成台灣繁體中文 → 中文逐幀同步顯示在英文正下方 → 下載高畫質 MP4。

## 快速開始

```bash
# 1. 安裝系統套件（Ubuntu / Debian）
sudo apt-get install -y ffmpeg fonts-noto-cjk fonts-noto-cjk-extra
# 2. 安裝 Python 套件（Python 3.10+）
pip install -r requirements.txt
# 3. 設定 Claude API 金鑰（擇一）：環境變數，或啟動後在網頁「⚙ 設定」輸入
export SUBZH_ANTHROPIC_API_KEY=sk-ant-...   # 也接受 ANTHROPIC_API_KEY
#    在 Claude Code 雲端環境請用 SUBZH_ANTHROPIC_API_KEY（ANTHROPIC_API_KEY 可能被平台保留）
# 4. 啟動
./run.sh            # 預設 http://0.0.0.0:8000 ，可用 PORT=9000 ./run.sh 改埠
```

開啟瀏覽器 `http://<伺服器IP>:8000`，員工即可在同一個網址使用。

## 使用流程

1. **上傳**：拖曳一支或多支影片（MP4/MOV/WEBM/MKV）。可選翻譯語氣（幽默／自然／專業）。勾選「分析完成後自動輸出」即為全自動批次模式。
2. **自動處理**（背景排隊，一次處理一支）：
   - OCR 辨識畫面中所有英文 → 依時間追蹤成「字幕段」→ 逐幀校正出現/消失時間。
   - Claude 看標註過的畫面，判斷哪些是**後製字幕/標題/文案**、哪些是**商品印刷字、品牌 Logo、場景文字**（後者不翻譯），並以整支影片上下文改寫成台灣用語的中文。
3. **預覽／編輯**：影片上即時疊加中文（與成品完全相同的圖層），可：
   - 修改每段中文（Enter 換行）、勾選/取消顯示、單句「↻ 重翻」或「😆 更有梗」。
   - 每段微調大小、上下/左右位置、放在英文上方或下方。
   - 「字幕樣式」：字重、文字色、描邊色與粗細、整體大小、間距、最多行數、最大寬度、陰影、底色框。
   - 被判定為商品文字的段落在「已忽略的文字」，必要時可手動啟用。
   - 「顯示英文偵測框」可檢查偵測結果；「上一幀/下一幀」逐幀檢查同步。
4. **輸出 MP4 → 下載**。列表頁可勾選多支「批次輸出」與「下載所選（ZIP）」。

## 技術說明

| 項目 | 作法 |
|---|---|
| 英文辨識 | RapidOCR（PP-OCR 模型，onnxruntime，CPU 即可）每秒取樣 5 幀；同幀文字行合併成區塊（多行標題視為一段） |
| 時間同步 | 以文字相似度＋框重疊追蹤同一段字幕；取樣點之間逐幀 OCR 校正，出現/消失時間**精準到幀** |
| 字幕/商品文字判斷 | Claude 視覺判斷（附編號框的畫面＋位置/移動/傾斜等特徵）；未設定金鑰時用規則判斷（水平、夠大、靜止或有一致動畫軌跡） |
| 翻譯 | Claude（預設 `claude-opus-5-5`，可在設定改 Sonnet 5.5），結構化 JSON 輸出，整支影片一次翻譯保持上下文連貫 |
| 動態跟隨 | 每個取樣點記錄英文框位置與字高，中文位置與縮放逐幀線性插值；靜止字幕鎖定位置避免抖動 |
| 自動排版 | 字級依英文字高；超過寬度自動平衡換行，超過行數自動縮小；下方空間不足或會壓到其他英文字幕時自動改放上方；不超出畫面 |
| 輸出 | 與分析相同的解碼管線（固定幀率、自動處理手機旋轉）逐幀合成，libx264 CRF 16、原解析度、原 FPS，音訊原封不動複製（非 MP4 相容格式如 Opus 則轉 320k AAC），`+faststart` |

設定頁可調整 CRF（越小越清晰）與編碼速度。資料存於 `data/jobs/<id>/`（原片、成品、job.json）。

## 測試

```bash
python3 tests/make_test_video.py tests/test_input.mp4      # 產生含靜態/移動縮放字幕＋商品文字的測試片
python3 tests/pipeline_offline.py tests/test_input.mp4 out.mp4   # 辨識→排版→輸出（不需 AI 金鑰）
python3 tests/check_sync.py tests/test_input.mp4 out.mp4   # 驗證中文與英文逐幀同步
node tests/e2e_browser.js /tmp                              # 瀏覽器端到端（需伺服器運行中）
```

## 限制與建議

- 處理速度（4 核 CPU）：每 10 秒影片約 30–40 秒分析＋ 5–10 秒輸出。
- 10-bit HDR 影片會輸出為 8-bit SDR H.264。
- 英文字幕若是逐字跳出（karaoke），中文會在整段期間顯示完整翻譯。
- 字幕淡入淡出時，中文以英文可被辨識的幀為準出現/消失（無淡入效果）。
